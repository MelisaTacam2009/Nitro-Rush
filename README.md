# 🏎️ NITRO RUSH

### Proyecto de Programador Junior

**Desarrollado por:** Melisa
 
## Descripción del proyecto

NITRO RUSH es un videojuego de carreras diseñado para
adolescentes de 13 a 15 años. El jugador deberá competir
contra diferentes rivales, superar obstáculos, utilizar
el nitro y completar diferentes niveles hasta convertirse
en el campeón.

A continuación se presentan las diferentes fases del
desarrollo del proyecto.

# FASE 1 REQUERIMIENTOS FUNCIONALES Y NO FUNCIONALES 
En esta sección encontrarás los requerimientos funcionales y no funcionales establecidos para el desarrollo de NITRO RUSH, donde se describen las funciones, características y condiciones que tendrá el videojuego.
# FASE 2 DIAGRAMA DE FLUJO DEL VIDEO JUEGO 
En esta sección encontrarás el diagrama de flujo de NITRO RUSH, donde se representa paso a paso el funcionamiento del videojuego, incluyendo el menú, las carreras, las decisiones, las victorias, las derrotas y los diferentes niveles.
# FASE 3 CÓDIGO 
En esta sección encontrarás el código fuente del videojuego NITRO RUSH, desarrollado en Python. El código contiene las funciones, clases, objetos, niveles, personajes, sistema de puntos, vidas y demás elementos necesarios para el funcionamiento del juego.
# FASE 4 PRESENTACIÓN PROGRAMADOR JUNIOR ORIENTADO A PROGRAMACIÓN A OBJETOS
