## Descripción del proyecto  
NITRO RUSH es un videojuego de carreras dirigido a adolescentes de 13 a 15 años. El jugador deberá competir contra diferentes rivales, superar obstáculos, utilizar el nitro y completar diferentes niveles hasta convertirse en el campeón.

A continuación, se presentan las diferentes fases realizadas para el desarrollo del videojuego.

# FASE 1 REQUERIMIENTOS FUNCIONALES Y NO FUNCIONALES 
En este apartado encontrarás la planificación de NITRO RUSH, donde se establecen las principales características que tendrá el videojuego y las condiciones que debe cumplir. Se incluyen aspectos como el menú, los carros, las carreras, los rivales, los niveles, el sistema de puntos, las vidas, el nitro y las opciones de victoria o derrota. También se consideran aspectos relacionados con la facilidad de uso, la claridad de los mensajes y el correcto funcionamiento del programa.
# FASE 2 DIAGRAMA DE FLUJO
Aquí se presenta la representación gráfica del funcionamiento del videojuego. El diagrama muestra el recorrido que seguirá el jugador desde la bienvenida y el menú hasta el desarrollo de las carreras. Para organizarlo se utilizan procesos, decisiones y conexiones que permiten observar qué sucede cuando el jugador gana, pierde, utiliza sus vidas, reintenta una carrera o completa todos los niveles.
# FASE 3 CÓDIGO DEL VIDEO JUEGO 
En este apartado se encuentra el código fuente de NITRO RUSH desarrollado en Python. El programa integra los elementos planteados anteriormente y permite que el jugador seleccione un carro, participe en carreras, compita contra rivales, utilice el nitro, consiga puntos y pierda o conserve vidas. Para su funcionamiento se aplican estructuras como condicionales, ciclos, funciones, listas, clases y objetos, además del módulo random para generar diferentes situaciones durante las carreras.
# FASE 4 PRESENTACIÓN PROGRAMADOR JUNIOR ORIENTADO A PROGRAMACIÓN A OBJETOS 
En esta etapa se crea una cuenta en GitHub y un repositorio para el proyecto NITRO RUSH. En el repositorio se organiza todo el trabajo realizado, donde se explica el videojuego, su funcionamiento, los personajes, niveles, programación utilizada y los conocimientos aplicados durante su desarrollo. Incluyendo el análisis, los requerimientos, el diagrama de flujo, el código y los documentos del proyecto.

También se agregan los archivos en PDF y la presentación final, dejando cada fase ordenada para facilitar la revisión del proyecto.
